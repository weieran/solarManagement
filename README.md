# solarManagement



# iot Hub 
https://github.com/Azure/azure-iot-sdk-python/blob/v3/README.md

Allows to receive messages from the iot hub
```bash
stop: stops the solar management
start: starts the solar management
```

# Credeentials
a credential file has to be created in /mnt/node/cfg/credentials.sh
and export the following variables
~~
export SRF_METEO_CLIENT_ID=
export SRF_METEO_CLIENT_SECRET=
export IOTHUB_DEVICE_CONNECTION_STRING=
~~
